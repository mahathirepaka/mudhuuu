# A Little Something for You — for Mudhuuu 💗

A personal React + CSS friendship proposal website built around the 9 real photos uploaded in this conversation.

## Run locally
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. In the terminal, run:
   ```powershell
   npm install
   npm run dev
   ```
4. Open the localhost URL printed by Vite.

## Included
- Mudhuuu welcome screen
- All 9 uploaded photographs displayed in the gallery and story sections
- Personal messages about hostel roommates, food, clothes, cooking, late-night talks, silly fights and caring
- Animated envelope letter
- Floating flower/hearts effects and responsive design
- Optional background music upload
- Friendship proposal: "Will you be my best friend forever?"
- Two gentle response choices

## Photos
The original uploaded photos are copied into `public/photos/` and referenced directly by the website. They are not retouched, filtered, face-swapped or replaced with stock photos.

## Note
You uploaded 9 photographs in this message. If you intended to use 10, add the remaining photo to `public/photos/` and add it to the `memories` array in `src/App.jsx`.

The response choices are on-screen only; they do not send notifications or store her answer.
